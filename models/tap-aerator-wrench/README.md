# Tap Aerator Wrench

I always find it cumbersome to use a pipe wrench or adjustable wrench
to screw the aerator out of a tap or bach into it, in order to descale it.
Which is a frequent thing if have hard tap water.

![Model Preview](./assets/wrench-model.png)

This specialized tool solves that and also protects your chrome finish.
Print in PETG or better to get enough strength.
